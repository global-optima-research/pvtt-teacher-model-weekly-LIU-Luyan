## 1. 研究领域

**视频目标分割（VOS）与电商视频智能编辑 Agent**。

本周重点完成 **SAM3 文本驱动分割** 在 PVTT 电商评测集上的全量复现，并将其与前期在 DAVIS 2017 上测试的四个经典 VOS 模型（SAM2/GSAM2、Cutie、DEVA、XMem）进行横向对比，为后续 Agent 中的 **模型路由策略** 提供实证依据。

## 2. 领域核心问题

**核心挑战：** 单一 VOS 模型无法覆盖电商视频的全部场景——商品尺度跨度大（耳环 vs 手提包）、拍摄形态多样（scene 短镜头 vs 未切分长视频）、交互复杂（手持遮挡、细链/半透明部件）。

**待解决的具体问题：**

1. **SAM3 在真实电商数据上的能力边界** 尚不明确——文本 prompt 能否替代点/框提示，在哪些品类和拍摄场景下可直接落地？
2. **多模型能力互补：** 前期四个 VOS 模型各有优劣，SAM3 作为新成员应如何与它们协同，而非简单替换？
3. **Agent 路由逻辑缺失：** 需要一套可执行的决策规则，根据商品类型、拍摄形态、运动状态选择合适的分割后端。

## 3. 技术方案

延续 week8 提出的 **「VLM 先验路由 + 动态采样 + 自适应分割引擎」** 框架。本周工作聚焦于 **补齐第五个路由节点（SAM3）** 并完成全量评测：

- **SAM3 复现：** 基于 `Sam3Processor` 文本 grounding 头，对 PVTT `source_videos_100`（98 视频）逐帧推理，与 GT mask 计算 IoU。
- **Prompt 设计：** 从文件名解析品类，映射至英文 prompt（如 `watch → wristwatch`）。
- **评测协议：** 每视频均匀抽 8 帧，与最小复现 demo 保持一致（方案 A）。
- **产出：** 完整推理流水线（断点续跑、失败容错）、定量报告与可视化 overlay。

## 5. 结论与发现

### 5.1 SAM3 复现结论

1. **整体可用：** 超过半数帧 IoU ≥ 0.7，SAM3 可作为电商商品分割的 **文本驱动基线专家**。
2. **品类分化明显：**
   - **强项（Mean IoU > 0.68）：** 手表（0.776）、手提包（0.765）、折扇（0.729）、钱包（0.689）——目标大、轮廓刚性、对比度高。
   - **弱项（Mean IoU < 0.55）：** 耳环（0.237）、项链（0.510）——目标极小、细链结构、强高光干扰。
   - **中等/分化：** 手镯（0.620）、墨镜（0.575，单 scene 内 0.05–0.94 波动大）、服装（0.597，样本少）。
3. **场景强依赖 scene 切分：** 无 scene 标签的完整长视频 Mean IoU 仅 **0.425**；有 scene 标签的短镜头可达 **0.85–0.93**。SAM3 更适合 **经 shot 检测切分后的商品短 clip**，而非 raw 长视频直接推理。
4. **与 SAM2 的互补关系：** SAM3 的优势在于 **零样本文本定位**（无需首帧点击/框选），劣势在于 **无视频时序传播**（本实验为逐帧图像推理）。后续可组合为「SAM3 文本定位首帧 → SAM2/Cutie 时序传播」的两阶段管线。

### 5.2 五模型横向对比

> **说明：** SAM3 在 PVTT 电商集（文本 prompt + 逐帧 IoU）上评测；其余四模型在 DAVIS 2017 验证集（点/框初始化 + 视频传播 + J&F 指标）上评测。二者数据集与指标不同，对比侧重 **能力画像与路由适用性**，而非直接数值排名。

#### 总体定量（DAVIS 2017，四模型）

| 模型 | J&F ↑ | TC ↑ | ΔArea% ↓ | 核心特点 |
|------|:-----:|:----:|:--------:|---------|
| **SAM2/GSAM2** | **90.87** | 79.44 | 4.41 | 综合最优；遮挡恢复强 |
| **Cutie** | 88.91 | **79.71** | **4.06** | 时序最稳定 |
| **DEVA** | 88.77 | 79.65 | 4.23 | 细小/半透明物体更保守 |
| **XMem** | 87.18 | 79.66 | 4.24 | 长期记忆；相似物体边界精 |
| **SAM3**（PVTT） | — | — | — | Mean IoU **0.62**；文本零样本定位 |

#### 各模型代表案例与能力画像

**① SAM2/GSAM2 — 大物体 + 遮挡恢复**

![SAM2 多物体场景 gold-fish（J&F=94.1）](../davis2017_comparison/gold-fish_frame00039.png)

- **擅长：** 大型边界清晰商品（包、鞋、家电）；快速运动遮挡后恢复（bmx-trees J&F=80.0）；多物体场景整体分割。
- **不擅长：** 半透明/边界模糊物体（paragliding 排名垫底）；极细结构（风筝线区域覆盖不足）；记忆膨胀导致 mask 偏大。
- **电商映射：** 静态展示的大件商品、手持大物（整包/整表）。

**② Cutie — 时序一致性优先**

![Cutie 遮挡场景 bmx-trees（J&F=76.6，TC=55.8%）](../davis2017_comparison/bmx-trees_frame00021.png)

- **擅长：** 长视频时序稳定（仅 27 帧 ΔArea 超标）；多物体 ID 一致性好。
- **不擅长：** 综合 J&F 略低于 SAM2；遮挡剧烈时与其他模型差距不大。
- **电商映射：** 需要 mask 时序平滑的多产品轮播视频；作为 SAM2 结果的 **时序兜底**。

**③ DEVA — 细小/半透明结构**

![DEVA 半透明伞面 paragliding-launch（J&F=65.6，本场景最优）](../davis2017_comparison/paragliding-launch_frame00040.png)

- **擅长：** 半透明、边界模糊物体（降落伞伞面）；细小配件分割更保守、少过分割。
- **不擅长：** 大物体场景略逊 SAM2；综合 J&F 排名第三。
- **电商映射：** 含纱巾、透明包装、细链/吊坠等 **半透明或细结构配件** 的商品。

**④ XMem — 相似物体 + 长期跟踪**

![XMem 多人相似场景 lab-coat（F=73.0 最高）](../davis2017_comparison/lab-coat_frame00023.png)

- **擅长：** 外观相似的多目标边界精度；长视频持久 ID 跟踪。
- **不擅长：** 综合 J&F 最低；小物体漏检。
- **电商映射：** 多款相似 SKU 同框展示；需要跨镜头保持同一商品 ID 的长视频。

**⑤ SAM3 — 文本零样本定位（本周新增）**

![SAM3 PVTT 四案例：手表/手镯/项链/耳环](../sam3/report_figures/sam3_qualitative.png)

- **擅长：** 文本 prompt 直接定位，无需人工点击；手表/包/钱包/折扇等 **刚性中等尺寸配饰**（IoU > 0.68）；scene 切分后的短商品镜头（IoU 0.85+）。
- **不擅长：** 极小珠宝（耳环 IoU 0.24）；未切分长视频（IoU 0.43）；无视频时序传播能力。
- **电商映射：** Agent 接收自然语言编辑指令时，**首选文本分割入口**；尤其适合「帮我分割视频里的手表」类交互。

### 5.3 Agent 模型路由逻辑（草案）

基于本周实验，后续 Agent 可按以下 **三层决策** 路由分割后端：

```
用户指令 + 视频输入
        │
        ▼
┌─────────────────────────────────┐
│  Layer 1: VLM 场景理解（首帧）    │
│  输出: 品类 / 尺度 / 交互类型 /   │
│        是否已切分 scene           │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│  Layer 2: 模型选择               │
│                                  │
│  有自然语言目标描述？              │
│    ├─ 是 → SAM3 文本定位首帧     │
│    └─ 否 → SAM2 点/框初始化      │
│                                  │
│  品类路由:                        │
│    手表/包/钱包/折扇 → SAM3 优先  │
│    耳环/项链/细链   → DEVA 优先   │
│    多相似 SKU      → XMem 优先   │
│                                  │
│  视频形态:                        │
│    未切分长视频 → 先 shot 检测    │
│    scene 短 clip → 直接分割       │
└──────────────┬──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│  Layer 3: 时序传播 + 质量兜底     │
│                                  │
│  SAM3 首帧 mask → SAM2/Cutie 传播│
│  时序抖动大 → Cutie fallback     │
│  遮挡/剧变 → 密集抽帧 + 局部窗口  │
│  跟踪丢失 → VLM 重识别（SeC 类）  │
└─────────────────────────────────┘
```

**关键路由规则：**

| 条件 | 路由目标 | 依据 |
|------|---------|------|
| 用户给出文本目标（"分割手表"） | SAM3 → SAM2 传播 | SAM3 文本零样本；SAM2 时序补全 |
| 品类 = 耳环/项链/手镯（细结构） | DEVA 或 SAM3+框提示 | SAM3 耳环 IoU 0.24；DEVA 细结构更保守 |
| 品类 = 手表/包/钱包（大刚性） | SAM3 单帧即可 | PVTT 上 Mean IoU > 0.68 |
| 视频无 scene 标签（长 raw） | 先 shot 检测，再送 SAM3 | 长视频 IoU 0.43 vs scene clip 0.85+ |
| 多相似商品同框 | XMem | lab-coat 场景 F 值最高 |
| 手持/遮挡/快速运动 | SAM2 + 密集抽帧 | bmx-trees 遮挡恢复最优 |
| 时序 mask 抖动 | Cutie fallback | ΔArea% 最低（4.06%） |

### 5.4 踩坑记录

1. **PVTT mask 为灰度非二值：** `masks/` 下约 70 级灰度，评测时需阈值化（>0），否则 IoU 偏低。
2. **SAM3 无 mask 输出：** 23 帧 `INFER_NO_MASK` 失败（2.93%），集中在特定手提包 scene 与墨镜长视频。
3. **长视频时间对齐误差：** 无 scene 标签视频的 8 帧均匀采样与 GT 帧对齐存在偏差，长视频 IoU 0.43 含一定评测噪声，可视作 **精度下界**。
4. **指标不可直接横比：** DAVIS J&F 与 PVTT IoU 评测维度不同，Agent 设计应建立 **分场景路由** 而非追求单一模型全覆盖。
